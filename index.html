Chapter 1 - Foundations of Information Systems

Core Distinctions & Strategic Frameworks
  • IT vs IS: IT is the toolset (hardware/software); IS is the integrated system that collects, processes, and transmits data to achieve structural targets.
  • Informed Users: Gain exponential value by understanding backend tech constraints and maximizing organizational tooling potential.
  • Digital Transformation: Fundamental structural redesign of customer relationships, internal processes, and entire business operations using IT.
  • E-Business vs E-Commerce: E-commerce is exclusively transacting value over the web; E-business comprises all digital aspects of running an enterprise.
  • E-Commerce Topologies: B2B (Enterprise-to-Enterprise), B2C (Retail to Consumer), C2C (Peer-to-Peer), B2G, and C2G.
Types of Information Systems inside Organizations
  • TPS (Transaction Processing Systems): Executes and records the daily routine transactions necessary to conduct business (e.g., POS terminal sales log).
  • FAIS (Functional Area Information Systems): Built exclusively to support an isolated department's internal mechanics (e.g., HR appraisal tools, Accounting ledgers).
  • ERP (Enterprise Resource Planning): Solves the "Isolated Silo" problem by forcing all separate FAIS databases to sync via a single, shared corporate data asset.
  • IOS (Interorganizational Information Systems): Systems connecting separate enterprises to orchestrate seamless external B2B operations (e.g., Supply Chain Management).

Chapter 01 - IS in Organizations & Disruptive Pillars

The Disruptive Technological Pillars
  • Big Data (The 5Vs): Oversized, complex data matrices defined strictly by Volume (scale), Velocity (speed), Variety (format diversification), Veracity (trustworthiness/cleanliness), and Value.
  • Social Computing: Infrastructure blending web collaboration with human context (wikis, social network frameworks) to drive massive crowdsourcing.
  • Mobile Computing: Continuous, portable, location/context-aware link to networks via modern wireless arrays.
  • Internet of Things (IoT): Linking everyday physical objects directly to network hubs via embedded sensors to achieve automated machine-to-machine data exchanges.
  • Cloud Computing: Elastic, on-demand distribution of shared computing architectures over the web (Models: IaaS = Infrastructure, PaaS = Platform, SaaS = Software).
  • Artificial Intelligence (AI): Emulating advanced human logical and perceptual workflows using deep learning algorithms, vision models, and automated robotics.
  • Blockchain: Cryptographically secure, immutable, fully decentralized transaction ledgers designed to eliminate intermediary human trust fallacies.

Chapter 03 - Data and Knowledge Management

Corporate Governance & Database Integrity
  • Data Governance: The official framework defining definitive ownership permissions, asset security parameters, and absolute regulatory compliance targets.
  • Master Data Management (MDM): Processes designed to tie down core operational master entities into an unambiguous corporate "single version of truth."
  • Relational Key Matrix: Primary Key uniquely identifies an isolated row. Foreign Key references a Primary Key in another table to force structural relational links.
  • Data Warehouses vs Data Marts: Warehouses store historical data for enterprise-wide analysis; Data Marts are down-scaled, department-specific analytical repositories.
  • Knowledge Management Cycle: The circular workflow tracking intellectual capital through six distinct milestones: Create → Capture → Refine → Store → Manage → Disseminate.

Chapter 04 - Telecommunications & Networking

Wired Media & Network Foundations
  • Physical Wired Mediums: Twisted-Pair (cheap, copper, highly susceptible to interference), Coaxial Cable (insulated copper with higher throughput capacity), Fiber-Optic (glass filaments pushing light signals; immune to interference, unparalleled speed).
  • Network Protocols: Structured system rulebooks formatting communications; TCP/IP acts as the universal standard underlying the Internet.
  • Domain Name System (DNS): The global translation directory mapping human-readable alphabetic URLs to numeric machine IP targets.
  • World Wide Web (WWW): A specialized internet utility parsing hypertext pages via HTTP/HTTPS protocols over web browsers.
